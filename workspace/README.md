# Danish Manzoor | Developer Workspace

A browser-local project board, snippet library and project link manager.

Open-source software under the MIT License. See `LICENSE` and keep that file.

## Run it on your computer
ES modules need a web server, so do not double-click `index.html`.
1. Open a terminal in this folder.
2. Run `python3 -m http.server 8000` (on Windows try `python -m http.server 8000`).
3. Open http://localhost:8000 in your browser.

## Change the look
Edit `config.js`: name, subtitle, photo path and accent colour. Your photo is assets/danish.jpg. To change it, replace that file (keep the same name).

## Sample data
The first projects, tasks and snippets are labelled **sample data**. Edit or delete them and add your own. Project links come from the resume.

## Data and limits
No backend, login, AI service or cloud sync. Data stays in this browser. Clearing browser data can remove it, so use Export backup. Snippets are stored as text and never run. Do not store passwords or API keys.
