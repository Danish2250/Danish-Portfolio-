# Danish Manzoor | Portfolio

A personal portfolio website. Open-source under the MIT License: see `LICENSE` and keep that file.

- `index.html` is the portfolio. Edit your content in `portfolio.config.js`.
- `workspace/` is a separate Developer Workspace app (project board, snippets, links). It is linked from the Projects section.

## Run locally
Open a terminal in this folder and run `python3 -m http.server 8000`, then open http://localhost:8000
(Windows: `python -m http.server 8000`).

## Note
The workspace shows sample data at first and stores your data only in your browser. No login, AI or cloud sync.
